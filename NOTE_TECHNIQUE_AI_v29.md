# Note technique v29

La v29 ajoute une IA créative locale dans le Studio.

Le moteur ne contacte aucune API externe.
Il fonctionne avec :
- intentions ;
- styles ;
- layouts ;
- palettes ;
- mots-clés ;
- règles de charte.

Fonctions :
- analyser un prompt ;
- choisir un format ;
- choisir un style ;
- choisir un layout ;
- générer une page Studio ;
- vérifier quelques règles de charte ;
- adapter une page vers un autre format ;
- générer des variantes ;
- transformer un texte ou document en visuel.

Limites :
- pas de génération d’image par IA ;
- pas de modèle de langage externe ;
- suggestions déterministes.
