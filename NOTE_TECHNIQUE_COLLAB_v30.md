# Note technique v30

La v30 ajoute une couche de collaboration locale.

Elle gère :
- rôle courant ;
- permissions ;
- workflow ;
- commentaires ;
- versions ;
- restauration ;
- validation charte ;
- publication ;
- packs par service.

Important :
Tout est localStorage côté navigateur.
Cela permet de tester la logique sans backend.

Pour un vrai usage entreprise :
- authentification ;
- comptes utilisateurs ;
- base de données ;
- API backend ;
- stockage fichiers ;
- droits réels ;
- logs serveur ;
- partage réseau.
