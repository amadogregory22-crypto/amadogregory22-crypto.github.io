# Recette Outlook — Signature RAGT

Date de création : 16 septembre 2026  
Statut : **validée par le demandeur pour les trois cibles de la première livraison**

Les contrôles intégrés au Studio sont automatiques. Cette fiche est la preuve attendue avant d’afficher qu’une version est validée dans un client Outlook.

## Préparation

1. Relever la version exacte du client et du système.
2. Dans le Studio, choisir le gabarit à vérifier puis utiliser **Copier la signature**.
3. Coller dans les paramètres de signature du client.
4. Créer un nouveau message, puis s’envoyer un message de contrôle.
5. Répéter avec les images chargées et avec les images distantes bloquées si le client le permet.

## Points à contrôler pour chaque gabarit A à I

- Nom, fonction, téléphones, e-mail, adresse, site et réseaux sont visibles et cliquables lorsque leur visibilité est activée.
- Le logo, le logo secondaire et la bannière gardent leurs proportions.
- Le QR Code est lisible après envoi lorsque l’option est active.
- Le slogan et les séparateurs gardent leur couleur et leur alignement.
- Il n’y a ni chevauchement, ni débordement horizontal, ni image manquante.
- Le message reçu conserve le rendu attendu dans le volet de lecture.

## Critère de publication

Une version peut être indiquée comme « validée » pour un client uniquement lorsqu’une ligne ci-dessus est complète et ne contient aucune anomalie bloquante. Une limitation acceptée doit être décrite précisément dans la colonne « Anomalies / décision ».

## Portail hors connexion

Télécharger **le portail collaborateur**, couper la connexion, l’ouvrir puis vérifier le logo, la bannière et le QR. Modifier le prénom ou l’e-mail, puis vérifier que le statut indique « QR Code régénéré localement » avant de copier. Si le portail signale une image non embarquée, cette image doit être remplacée avant diffusion.
