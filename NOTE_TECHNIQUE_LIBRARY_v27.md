# Note technique v27

La v27 ajoute une bibliothèque Canva-like dans le Studio.

Fonctions :
- catalogue seed en JSON ;
- assets utilisateur sauvegardés dans l’état local ;
- templates utilisateur sauvegardés dans l’état local ;
- import/export JSON ;
- favoris ;
- tags ;
- filtres catégorie/pack ;
- insertion directe dans le canvas ;
- glisser-déposer vers le canvas.

Le but est de séparer clairement :
- Studio : création ;
- Bibliothèque : stockage/recherche ;
- Templates : réutilisation ;
- Export : production.
